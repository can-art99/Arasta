# Arasta ses dosyaları

Bu klasöre .mp3 / .ogg dosyası koyup adını `list.json` içine yazınca oyun sentez ses yerine o dosyayı çalar.
Örnek list.json: ["tap.mp3","cut.mp3","amb_rain.mp3"]

| Dosya adı | Nerede çalar |
|---|---|
| tap | buton dokunuşu |
| swoosh | sekme geçişi |
| pick | bahçede toplama |
| cut | makas / kesim |
| stitch | dikiş |
| punch | delik açma |
| glue | tutkal |
| sand | zımpara |
| skive | bıçakla inceltme / oyma |
| wax | cila, şekillendirme, karıştırma |
| brush | boya sürme |
| drop | renk seçme, parça bırakma |
| good / bad | başarılı / başarısız adım |
| coin | satış, altın |
| bell | kapı zili / akşam |
| plant / seed / water | ekim, sulama |
| amb_rain | yağmur döngüsü (loop) |
| amb_wind | rüzgâr döngüsü (loop) |
